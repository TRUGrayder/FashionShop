Báo cáo tiến độ TX1

Về dự án Fashion Shop

Đề tài: Xây dựng website thương mại điện tử tích hợp trợ lý AI theo kiến trúc phân tầng sử dụng Spring Boot, MySQL và Qdrant cho cửa hàng thời trang.

Thực hiện: Nhóm 8
  • Kiến trúc: Layered Architecture (Controller → Service → DAO (Pure JDBC) → MySQL Database).
  • Backend: Java 17, Spring Boot 3.2.5.
  • Frontend: Thymeleaf, Bootstrap 5.3.3, Modular Fragments, Static CSS & JS.
  • Database: MySQL 8.x / MariaDB.
